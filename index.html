Benchside

Nanopore telomere tools for the Field lab. Basecall POD5 with Dorado and watch the run live, pull the telomeric reads out of a run, and keep every run's settings and results in one place.

Install

  1. Download the Windows installer (Benchside_…_x64-setup.exe) above.
  2. Open it. Windows may say “Windows protected your PC”. Click More info, then Run anyway. This appears because Benchside isn't signed with a paid certificate yet.
  3. Finish the installer. It installs for your account only, so it doesn't need administrator rights. The first time, it may download Microsoft's WebView2 component, which needs an internet connection.
  4. Open Benchside from the Start menu, then follow Set up.
Basecalling on a laptop. Dorado is fast on an NVIDIA GPU. Without one it runs on the processor, which is fine for a short test but far too slow for a full sup run; do those on the lab computers. Everything else in Benchside works the same on any computer.

On the lab computers Dorado lives inside WSL (Windows Subsystem for Linux), where it uses the NVIDIA GPU. Benchside is installed on Windows as usual and runs Dorado inside WSL for you.

  1. Install Benchside as in the Windows steps.
  2. Check Dorado. Open Settings → Dorado. If Dorado is installed in WSL (on its PATH, or in a folder like ~/dorado/bin/dorado) it shows with a WSL · Ubuntu label. If it isn't, choose Into WSL (Ubuntu) next to Download Dorado.
  3. Check the GPU. In the WSL terminal, nvidia-smi should list the graphics card. If it doesn't, update the NVIDIA driver on Windows; WSL uses the Windows driver, so don't install a Linux NVIDIA driver inside WSL.
  4. samtools is only needed to remove unmapped reads after alignment. Install it in WSL with sudo apt install samtools.
Where files can be. POD5 and reference files on Windows drives work (Benchside passes them to Dorado as /mnt/c/…), and so do files inside WSL (\\wsl$\Ubuntu\…). Network drives aren't visible inside WSL: copy the POD5 to a local drive first. The commands each run shows are the ones to type in the WSL terminal, so a run can be repeated by hand.
  1. Download the Mac version (Benchside_…_aarch64.dmg) above, open it and drag Benchside to Applications.
  2. Open it once from Applications. macOS will say it can't check Benchside for malicious software. Open System Settings → Privacy & Security, scroll down, click Open Anyway next to Benchside and confirm. You only do this the first time.
  3. Follow Set up.
Apple Silicon only. Benchside is built for M-series Macs. Oxford Nanopore no longer makes Dorado for Intel Macs, so there's no Intel version.

Set up

  1. Choose the Benchside folder. The first screen asks where results go. Each run gets a dated folder inside it.
  2. Dorado. Settings → Dorado finds Dorado if it's installed, or downloads it from Oxford Nanopore. Updates to Dorado are a button there too, and the version an update replaces is kept so you can switch back.
  3. Add the tools you use. Add tools in the sidebar: Basecalling and POD5 Telomere Extraction.
  4. Models. Basecalling → Models shows the Dorado models on the computer. Point the models folder at the lab's models, download more there, or let runs download what they need the first time.
  5. Try a short run. Basecalling → Start a run, choose a POD5 file, open Advanced and set Read limit to 500, then Start run. It should finish in a minute or two.

Updating

When a new version is published, Benchside's Home page says so with a link back here. Download it and install it over the old one. Settings, run history and results are kept.

Something not working? In Benchside open Logs, click Save as file and send the file to Akhil.
